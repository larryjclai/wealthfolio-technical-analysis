## 持倉成本線

- 白色虛線，價格軸標記「持倉均價」，可獨立開關，附顏色圖例。
- 平均成本 = 同股票、同行情幣別的剩餘帳面成本總和 ÷ 剩餘股數總和。例：10 股成本 1,000 加 30 股成本 6,000，均價為 175，不是兩個帳戶單價的簡單平均。
- 使用 Wealthfolio SDK 的 `Holding.costBasis.local`；不重播歷史交易，不假定 FIFO，不拿本位幣成本與外幣行情比較。費用、拆股與剩餘成本認列依主程式。
- 成本缺漏、幣別不一致、空頭或無效數字會說明原因，不以部分帳戶推估。可處理零成本與零股；已平倉部位不畫線。
- 顯示股數、帳戶數、資料日期；跨帳戶資料日期不同時提示同步。這是目前持倉成本水平線，並非歷史成本走勢。

## 提醒歷史

- 記錄啟用、修改、觸發、確認、重新開始、停用、拆股待確認、行情失敗／恢復及監控暫停／恢復。
- 觸發紀錄保留首次觸發時的高點、價格與提醒價，後續反彈不改寫；記錄時間與行情日期分開呈現。
- 確認、重新開始或移除股票不刪除過去事件。可按股票、事件篩選，每頁 20 筆。
- 連續行情失敗只記錄第一次失敗與恢復，避免每輪重複記錄；失敗快照為上次有效行情，不代表新的成交價。
- 保留最近 300 筆內，並將完整設定與歷史控制在約 220 KB 以下，為 SDK 每個儲存鍵約 250 KB 上限保留空間。容量不足先移除最舊事件並顯示移除數量；設定本身過大則拒絕寫入並保留上次成功狀態。
- 設定與事件一起儲存；儲存失敗不發布成功事件或新通知。舊版僅能匯入已存在的觸發，不補造缺失歷史。本次重新編號仍使用先前 2.4.0 的儲存格式 v2；僅支援格式 v1 的舊程式會拒絕讀取此格式。

## 背景監控範圍

使用者指定：Wealthfolio 保持開啟，切換到其他頁面也要監控。

監控服務現在由套件啟動／停用生命週期持有，不依賴技術分析頁是否顯示。每輪完成後等待 60 秒再檢查，不重疊請求；可暫停／恢復並保存選擇。停用套件會清除排程，也會忽略尚未完成的行情回應。

**每次重新開啟 Wealthfolio 後，必須先進入套件一次。** 這是主程式 3.8.0 對有頁面入口套件的延後啟動機制。之後切到其他頁面，主程式隱藏但保留套件環境，背景服務可繼續工作。依據官方 [套件啟動協調程式](https://github.com/wealthfolio/wealthfolio/blob/v3.8.0/apps/frontend/src/addons/activation-coordinator.ts) 與 [iframe 管理程式](https://github.com/wealthfolio/wealthfolio/blob/v3.8.0/apps/frontend/src/addons/iframe/addon-iframe-manager.ts) 的 `detachRoute`／`hideFrame`／`stopRuntime` 行為。

主程式關閉或電腦休眠不保證監控；系統節流也可能延後。恢復後補查可取得的日 K，無法重建未被觀察到的短暫盤中穿越。提醒是主程式內提示與歷史紀錄，不包含作業系統通知、自動下單或主程式關閉後的常駐服務。主圖行情仍為載入時快照，提醒清單有獨立檢查時間。

## 驗證

- TypeScript 檢查、72 個測試及正式建置／封裝驗證。
- 新增跨帳戶剩餘成本、幣別／成本缺失、歷史遷移、原子保存失敗、事件保留上限、UTF-8 容量、重設保留舊事件、失敗去重、離頁仍監控、暫停／恢復、慢請求不重疊及停用後忽略回應等測試。
- 本機模擬頁顯示 40 股、兩帳戶均價 175 的白色成本線與圖例。卸載分析頁、切到模擬主程式其他頁後，再模擬跌價 30%，下一輪仍出現 20% 回落提醒；返回可見觸發歷史。已操作確認提醒、歷史篩選及暫停／恢復，瀏覽器未記錄警告或錯誤。
- 模擬資料、帳戶及儲存皆為測試用。尚未把新版安裝到使用者的真實 Wealthfolio，未宣稱完成真實帳戶與 Yahoo 連線端到端驗證。
- 無新增權限。沿用帳戶、持倉、交易紀錄唯讀權限與 Yahoo 網路查詢；持倉成本和交易紀錄不送至 Yahoo。
