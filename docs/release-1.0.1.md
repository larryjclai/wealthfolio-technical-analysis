# 1.0.1 — 每日收盤檢查與總覽操作修正

日期：2026-09-19。依使用者回饋簡化既有提醒與操作流程，保留成本線、買賣點、歷史與原有追蹤設定。

## 行情錯誤與休市

OHLC 全空、成交量空或零的日 K 佔位列直接略過。週末或平日假期沒有新交易時，沿用最近有效交易日，不另外產生「過期」或空白 K 警告。這是資料形狀辨識，沒有加入交易所假日日曆；不能宣稱每筆空值皆確定由休市造成。部分缺值、有成交量但全空價格、矛盾高低價仍須警告。404 代表供應商查不到行情，提示核對代碼、上市／上櫃與支援市場，不冒充休市成功。

## 每日提醒

移除 BackgroundMonitor、60 秒排程與背景監控按鈕。頁面進入或回到可見狀態時檢查，每檔依交易所當地日期每日成功抓取一次，日期持久保存。沒有背景計時器；關閉 App、留在別頁或一直不操作時不會定時抓價。尚未回傳的網路請求受 SDK 限制不能取消，但離頁後忽略回應並停止下一檔請求。手動「立即檢查日 K」可略過每日限制，慢速請求不重疊。

僅用 closed 日 K：最高價提高追蹤高點，收盤價小於等於門檻時提醒。首次設定改用最近收盤價作基準；舊高點與舊觸發事件不刪除。沒有新收盤價不新增觸發；補查漏掉的已收盤資料並保留首次觸發。若當日盤中已自動掃描，收盤後須手動檢查，或等次日回到套件再掃。行情失敗允許重試，不記成成功。

儲存沿用 v2，新欄位 dailyScans 在舊設定中可缺省。保留舊監控事件供查閱，舊監控開關不再控制掃描。

## 總覽與指標

進入個股時總覽保留於記憶體，返回不發出新的總覽行情請求，保留篩選、排序、水平表格位置與頁面捲動位置。按重新整理或重進套件才重新載入。Wealthfolio 3.8 把離頁 iframe 尺寸改為 0 × 0；套件以尺寸事件辨識此時結束畫面工作階段，恢復尺寸時建立新工作階段。沒有存取主程式其他頁面的資料。

總覽隱藏持有股數；個股成本摘要保留。支撐／壓力明確標示「20 日區間」並解釋與 MA20 不同：前者取前期高低，後者取含最新 K 的收盤平均；20 日不是普遍唯一標準。

## 驗證

- 79 個測試通過，含每日去重、重開後去重、交易所時區、未收盤不觸發、休市沿用、失敗重試、離頁忽略回應、空白佔位列和 404。
- TypeScript、正式建置及安裝包內容驗證。
- 本機合成資料操作：篩選並排序後進入 AMD 再返回，行情請求維持 3 次，篩選與排序保留；離開再進入只增加總覽的 1 次請求，同日不重掃提醒；手動掃描後正確觸發 20% 回落提醒。
- 390px 畫面沒有整頁水平溢出；進出個股後頁面捲動位置還原為 512px。總覽沒有股數欄，個股顯示 40 股。
