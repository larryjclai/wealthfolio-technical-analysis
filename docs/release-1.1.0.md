# v1.1.0 — MA5 選配篩選與持倉觀察清單

本版新增 MA5 選配篩選，並包含前版 1.0.4 的三種持倉觀察清單、MA20 條件、資料狀態檢查與 Wealthfolio 內建風格示警。每檔列出判斷日期與原因，協助先檢查中長期趨勢，再看短期條件。分類是檢查清單，不會替你下單。

## 1.1.0 新增

- **MA5 四種可選條件**：高於 MA5、低於 MA5、MA5 上穿 MA20、MA5 下穿 MA20。位置採最新行情，兩均線交叉比較最近兩筆已收盤日 K 的當日 MA5 與 MA20；前一日可相等，最新日須嚴格高於／低於，持續在同一側不會重複算成交叉。
- **按需搭配**：未勾選 MA5 時不限制結果，勾選後沿用「符合任一項」或「全部符合」，再與所選觀察清單取交集。加碼／續抱／減碼分類仍使用 MA20／MA60／MA240 的固定條件，MA5 可另外選作短期條件。

## 延續 1.0.4 的完整功能

- **三種觀察清單**：加碼觀察需收盤 > MA60 > MA240，且 MA60／MA240 都比 5 個已收盤交易日前高；再符合 MA20 新突破或前日觸及 MA20 後收盤回升，收盤距 MA20 不超過 3%。上升趨勢完整、收盤高於 MA20，但不符合新時機時，列入續抱觀察。
- **風險優先**：收盤跌破前 20 日區間低點、低於正在下降的 MA60，或移動停利已觸發，優先列入減碼檢查。確認停利提醒後仍保留分類，直到重新開始追蹤或停用；其他技術風險仍會另外判斷。
- **MA20 四種條件**：高於、低於、收盤突破、收盤跌破。均線位置採最新行情，交叉與觀察分類只使用已確認收盤的日 K，區分目前位置與新的交叉。
- **多條件交集**：多選可用「符合任一項」或「全部符合」，再與觀察清單同時篩選；從個股返回總覽保留原來的選擇。
- **資料狀態優先**：加碼／續抱至少需要 245 筆已收盤日 K；不足時單獨標示。提醒設定未就緒、資料失敗／待核對、行情日期不同步或異常 OHLC 日 K 被剔除時，原本的正向分類改列待觀察，既有減碼風險保留。
- **Wealthfolio 內建風格示警**：提醒中心使用圓形三角驚嘆號，無待處理事項顯示灰色，行情失敗／價格待核對顯示黃色，未確認的停利提醒或設定錯誤顯示紅色。行情注意事項採相同樣式。

觀察分類與交叉的日期可能早於最新行情日期；總覽與停利檢查各有自己的行情快照。發現日期不同步時，重新整理總覽並在提醒中心按「立即檢查日 K」，再核對原因與日期。

5 日比較與 3% 門檻是固定觀察規則，尚未策略回測；RSI 超賣或 MA5 條件單獨不會列入加碼觀察，仍需結合基本面、持倉比例與可承受損失。完整公式見 [計算與資料說明](https://github.com/larryjclai/wealthfolio-technical-analysis/blob/v1.1.0/docs/calculation-notes.md)。

下載附件 `addon.zip`，在 Wealthfolio「設定 → 擴充功能 → 從檔案安裝」匯入更新。需使用 Wealthfolio 3.8.0 或更新版本，既有追蹤設定與提醒歷史保留。
