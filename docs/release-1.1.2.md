# v1.1.2 — 統一提醒中心與原生下拉選單

Comportfolio 本版修正兩項介面問題：

- **統一提醒入口**：總覽行情注意事項與停利狀態收進同一個提醒中心。未確認停利或設定錯誤顯示紅色，優先於行情問題／價格待核對的黃色；沒有待處理事項為灰色。有追蹤問題時先開移動停利，只有總覽行情問題時直接開行情注意事項。
- **Wealthfolio 共用介面**：市場、多選方式、Pivot、歷史股票與事件五個下拉採用主程式的 Select，提醒中心改用 Sheet 側邊面板，修正面板內選單浮層並支援鍵盤操作。Esc 先關選單、再關面板，焦點回到提醒入口。

延續 [1.1.1 的完整功能](https://github.com/larryjclai/wealthfolio-technical-analysis/releases/tag/v1.1.1)。技術規則、套件識別碼、設定與歷史儲存格式、權限維持不變；共用 UI 由 Wealthfolio 提供，套件不另打包其 JavaScript。

## 驗證

- 119 項自動化測試、TypeScript 檢查與正式建置通過。
- 模擬資料預覽完成桌面 1280px 與窄螢幕 390px 檢查，整頁無橫向溢出；下拉鍵盤操作、分層 Esc、關閉焦點回入口皆通過，包含個股返回總覽的情況。
- 紅黃問題並存時只顯示紅色；確認停利後降為黃色，行情恢復後轉灰色。

介面驗證採用模擬資料，尚未在實際 Wealthfolio 主程式安裝新版驗證。本機預覽有共用 UI 的翻譯初始化警告，已確認下拉操作與自訂中文標籤正常；主程式的翻譯整合仍待實機確認。

下載附件 `addon.zip`，在 Wealthfolio「設定 → 擴充功能 → 從檔案安裝」匯入更新，再從側欄開啟 **Comportfolio**。需使用 Wealthfolio 3.8.0 或更新版本。
