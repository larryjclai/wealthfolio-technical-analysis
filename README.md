# Wealthfolio Technical Analysis

在 Wealthfolio 中查看台股、美股的技術指標、持倉成本與買賣點，並為個別股票設定移動停利提醒。

## 安裝

1. 使用 **Wealthfolio 3.8.0 或更新版本**。
2. 到 [最新版本下載頁](https://github.com/larryjclai/wealthfolio-technical-analysis/releases/latest) 下載附件 **addon.zip**，不需要解壓縮。
3. 在 Wealthfolio 開啟「設定 → 擴充功能 → 從檔案安裝」，選取下載的檔案並確認所需權限。
4. 從側邊欄開啟 **Technical Analysis**。

更新時同樣匯入新版 `addon.zip`，既有的追蹤設定與提醒歷史會保留。

## 可以做什麼？

- **持倉總覽**：集中查看最新日 K 價格、漲跌、均線、RSI、20 日區間支撐／壓力與 52 週範圍，並依訊號篩選股票。
- **個股圖表**：切換 SMA、EMA、布林通道、RSI、支撐／壓力與 Pivot；圖例標示各條線的顏色。
- **自己的交易紀錄**：在圖上查看實際買入、賣出點，以及目前持倉平均成本線。
- **移動停利提醒**：逐檔設定回落百分比，高點隨後續已收盤日 K 創新高而上移。
- **提醒中心**：從右上角鈴鐺查看追蹤清單、待確認提醒與歷史紀錄。

## 開始使用

### 查看持倉與個股

開啟套件後會載入持倉。點選股票名稱進入個股圖表，勾選想看的指標；也可使用「查詢股票」查看未持有的股票。

總覽上方可篩選均線、RSI、52 週高低點等訊號；選擇多個條件時，符合其中一項就會顯示。從個股返回總覽會保留原本的資料、篩選與捲動位置，需要更新行情時按「重新整理」。

**20 日區間與 MA20 不同：**區間支撐／壓力取最新交易日前 20 個已收盤交易日的最低／最高價；MA20 則是最近 20 日收盤價的平均，包含最新日 K。

### 設定移動停利

1. 進入個股頁，在圖表下方找到「移動停利提醒」。
2. 輸入回落百分比，例如 **20**，再按「啟用提醒」。
3. 起始高點留空時，從最近已收盤日 K 的收盤價開始；也可手動輸入起始高點。
4. 後續以已收盤日 K 的最高價更新追蹤高點，**只升不降**。收盤價回落至提醒價或更低時，會顯示提醒。

例如追蹤高點為 100、回落設定為 20%，提醒價就是 80。之後高點升至 120，提醒價也會提高到 96。

**檢查時間：**每天首次開啟或回到套件時檢查一次，依股票市場當地日期判定。若當天已在收盤前檢查過，收盤後可開啟右上角鈴鐺，按「立即檢查日 K」。停留頁面不會定時掃描，離開套件或關閉 App 後也不會在背景監控。

右上角鈴鐺的數字代表待確認提醒。確認提醒會保留紀錄；要開始新一輪追蹤，請在個股頁按「重新開始追蹤」。不再需要時可按「停用」。

## 使用須知

- 行情來自 Yahoo Finance，可能延遲；休市時沿用最近有效交易日。移動停利使用已收盤日 K，不會因盤中碰到提醒價就觸發，也不會自動下單。
- 成本線代表目前持倉均價；買賣點使用 Wealthfolio 的實際交易紀錄。拆股後，原始成交價可能與調整後的歷史 K 線不同；若追蹤顯示拆股提示，請核對價格後重新開始。
- 套件需讀取帳戶、持倉與交易紀錄；交易紀錄不會傳送至 Yahoo Finance。
