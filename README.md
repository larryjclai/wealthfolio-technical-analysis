# Comportfolio

Your portfolio compass.

看清持倉趨勢與風險。

在 Wealthfolio 中查看台股、美股的技術指標、持倉成本與買賣點，並為個別股票設定移動停利提醒。

## 安裝

1. 使用 **Wealthfolio 3.8.0 或更新版本**。
2. 到 [最新版本下載頁](https://github.com/larryjclai/wealthfolio-technical-analysis/releases/latest) 下載附件 **addon.zip**，不需要解壓縮。
3. 在 Wealthfolio 開啟「設定 → 擴充功能 → 從檔案安裝」，選取下載的檔案並確認所需權限。
4. 從側邊欄開啟 **Comportfolio**。

更新時同樣匯入新版 `addon.zip`，既有的追蹤設定與提醒歷史會保留。

## 可以做什麼？

- **持倉總覽**：集中查看最新日 K 價格、漲跌、均線、RSI、20 日區間支撐／壓力與 52 週範圍，並依觀察清單與技術條件篩選股票。
- **觀察清單**：分為「加碼觀察」「續抱觀察」「減碼檢查」，每檔列出判斷日期、價格與符合原因。
- **個股圖表**：切換 SMA、EMA、布林通道、RSI、支撐／壓力與 Pivot；圖例標示各條線的顏色。
- **自己的交易紀錄**：在圖上查看實際買入、賣出點，以及目前持倉平均成本線。
- **移動停利提醒**：逐檔設定回落百分比，高點隨後續已收盤日 K 創新高而上移。
- **提醒中心**：從右上角三角驚嘆號查看追蹤清單、待確認提醒與歷史紀錄。

## 開始使用

### 查看持倉與個股

開啟套件後會載入持倉。點選股票名稱進入個股圖表，勾選想看的指標；也可使用「查詢股票」查看未持有的股票。

總覽上方可篩選均線、RSI、52 週高低點等訊號。選擇多個條件時，預設「符合任一項」；改成「全部符合」即可找出條件的交集。先選觀察清單，再勾技術條件，兩者需同時成立。各條件旁的數字是所選觀察清單中該條件單獨符合的檔數，表格才是多選後的結果。

MA20 有四個條件：「高於 MA20」「低於 MA20」「收盤突破 MA20」「收盤跌破 MA20」。高於／低於看最新行情位置，可能包含未收盤日 K；突破／跌破比較最近兩筆已確認收盤的日 K，代表新的交叉，不會把一直高於均線當成再次突破。

MA5 是可選的短期篩選，提供「高於 MA5」「低於 MA5」「MA5 上穿 MA20」「MA5 下穿 MA20」。高於／低於採最新行情；上穿／下穿比較最近兩筆已收盤日 K 的當日 MA5 與 MA20。未勾選時不限制持股，勾選後依任一／全部符合模式與其他技術條件一起篩選。三種觀察清單仍使用 MA20／MA60／MA240 的固定條件，MA5 不會單獨決定分類。

從個股返回總覽會保留原本的資料、篩選與捲動位置，需要更新行情時按「重新整理」。若部分股票無法取得行情，可點右上角的三角驚嘆號查看原因。

**20 日區間與 MA20 不同：**區間支撐／壓力取最新交易日前 20 個已收盤交易日的最低／最高價；MA20 則是最近 20 日收盤價的平均，包含最新日 K。

### 使用觀察清單

| 清單 | 主要條件 |
| --- | --- |
| 加碼觀察 | 收盤 > MA60 > MA240，MA60／MA240 均上升；再符合 MA20 新突破或回檔回升，收盤距 MA20 不超過 3% |
| 續抱觀察 | 同樣的中長期上升趨勢，收盤高於 MA20，尚未符合加碼條件 |
| 減碼檢查 | 收盤跌破前 20 日區間低點，或低於正在下降的 MA60，或已觸發自己的移動停利條件 |

「上升」比較目前均線與 5 個已收盤交易日前的值。加碼／續抱至少需要 245 筆已收盤日 K；沒有完整中長期資料時顯示「資料不足」。其餘顯示「待觀察」，可在「全部持股」查看。每檔只歸入一種分類，減碼檢查優先。

觀察分類與 MA20 交叉只使用已收盤日 K，判斷日期可能早於旁邊的最新行情日期。提醒設定未就緒、讀寫錯誤、停利行情失敗、價格待核對、行情日期不同步，或當次行情資料剔除異常日 K 時，原本的加碼／續抱改列待觀察，既有風險條件仍保留。請先查看原因並更新資料。完整條件見 [計算與資料說明](docs/calculation-notes.md)。

這些是檢查清單，沒有替持股估值或計算適合的加碼金額；RSI 超賣單獨不會列入加碼觀察，也不會自動買入或賣出。MA5 可作為另外勾選的短期條件。

### 設定移動停利

1. 進入個股頁，在圖表下方找到「移動停利提醒」。
2. 輸入回落百分比，例如 **20**，再按「啟用提醒」。
3. 起始高點留空時，從最近已收盤日 K 的收盤價開始；也可手動輸入起始高點。
4. 後續以已收盤日 K 的最高價更新追蹤高點，**只升不降**。收盤價回落至提醒價或更低時，會顯示提醒。

例如追蹤高點為 100、回落設定為 20%，提醒價就是 80。之後高點升至 120，提醒價也會提高到 96。

**檢查時間：**每天首次開啟或回到套件時檢查一次，依股票市場當地日期判定。若當天已在收盤前檢查過，收盤後可開啟右上角提醒中心，按「立即檢查日 K」。停留頁面不會定時掃描，離開套件或關閉 App 後也不會在背景監控。

提醒中心的驚嘆號：灰色表示沒有待處理事項，黃色表示行情更新失敗或價格需要核對，紅色表示有尚未確認的移動停利提醒或設定載入／儲存錯誤。滑鼠停留可查看摘要與待確認筆數，點擊查看詳細內容；紅色不代表自動賣出。總覽的行情注意事項另有黃色驚嘆號，只在有資料提示時顯示。

確認提醒會保留紀錄、清除待確認狀態；該持股仍列入「減碼檢查」，直到在個股頁按「重新開始追蹤」或「停用」。若還有技術風險條件，重設／停用後仍可能列入減碼檢查。圖示顏色反映待處理事項，與持股的觀察分類分開判斷。

## 使用須知

- 行情來自 Yahoo Finance，可能延遲；休市時沿用最近有效交易日。移動停利使用已收盤日 K，不會因盤中碰到提醒價就觸發，也不會自動下單。
- 成本線代表目前持倉均價；買賣點使用 Wealthfolio 的實際交易紀錄。拆股後，原始成交價可能與調整後的歷史 K 線不同；若追蹤顯示拆股提示，請核對價格後重新開始。
- 套件需讀取帳戶、持倉與交易紀錄；交易紀錄不會傳送至 Yahoo Finance。
